# Undangan Pernikahan Prasetia & Aviva

## File
- `undangan-pernikahan-prasetia-aviva.html` — file utama undangan pernikahan interaktif.
- `README.md` — petunjuk penggunaan.

## Cara menggunakan
1. Simpan kedua file dalam folder yang sama.
2. Buka `undangan-pernikahan-prasetia-aviva.html` menggunakan browser.
3. Untuk membagikan sebagai link publik, unggah file HTML ke layanan hosting statis/web hosting.

## Isi dan fitur
Undangan memuat informasi Prasetia & Aviva, tanggal acara 11 September 2026, waktu 08.00 WIB sampai selesai, lokasi kediaman mempelai pria, galeri foto, kado digital, musik latar, countdown, animasi scroll, lightbox galeri, dan efek kelopak bunga.

## Catatan
Foto-foto sudah tertanam langsung di dalam file HTML, sehingga file HTML dapat digunakan sebagai satu berkas mandiri.
